💰 Hệ thống Quản lý Chi tiêu Cá nhân

Đây là một dự án Full-Stack Web Application giúp người dùng quản lý toàn diện các hoạt động tài chính cá nhân. Ứng dụng hỗ trợ theo dõi thu nhập, chi tiêu, thiết lập hạn mức cho từng danh mục, cũng như quản lý nguồn tiền (tiền mặt, ngân hàng, ví điện tử).

Chức năng chính

Xác thực người dùng: Đăng nhập, Đăng ký, Quên mật khẩu/Đặt lại mật khẩu

Trang chủ: Hiển thị số dư tổng, thu nhập, chi tiêu, giao dịch gần nhất, hạn mức và danh mục

Quản lý giao dịch: Thêm/sửa/xóa, lọc giao dịch theo loại (thu nhập/chi tiêu), danh mục, nguồn tiền, ngày, số tiền; sắp xếp theo ngày hoặc số tiền

Quản lý danh mục: Thêm/sửa/xóa danh mục, hỗ trợ tìm kiếm, có sẵn danh mục mặc định và cho phép tùy chỉnh thêm

Hạn mức chi tiêu: Quản lý hạn mức, số dư còn lại, % đã dùng; hỗ trợ thêm/sửa/xóa

Nguồn tiền: Quản lý nhiều nguồn tiền; số dư cập nhật tự động theo giao dịch; hỗ trợ vô hiệu hóa khi không còn sử dụng

Thông tin tài khoản: Hiển thị thông tin cá nhân, thay đổi mật khẩu

Ràng buộc dữ liệu: Khi xóa danh mục hoặc nguồn tiền, các giao dịch liên quan sẽ bị xóa theo

🛠️ Công nghệ sử dụng

Backend: Java, Spring Boot

Frontend: ReactJS, Redux

Database: MySQL

🚀 Cách cài đặt & chạy dự án

Yêu cầu

Spring Tool Suite / IntelliJ / Eclipse (có hỗ trợ Spring)

Visual Studio Code

Các bước thực hiện

Khởi động Backend (Database đã tích hợp trong backend nên không cần chạy MySQL)

Mở project backend bằng Spring Tool Suite

Run project để khởi động server

Khởi động Frontend

Mở project frontend bằng VSCode

Chạy 'npm install' trong terminal

Chạy 'npm run dev' và truy cập tại http://localhost:3000
